# K2P 4.4：首次迁移、内存检查及回滚边界

2026-11-02。此文档是维护方案，不是刷写或重启指令。构建与离线验证通过的文件仍是候选；实际执行需要另行授权的现场维护窗口。仓库不包含设备口令、Factory、整片或配置备份。

## efd2 首次升级由谁执行

若当前运行源码是 `efd2ac32afceb4bf25ce738e6f538599985c6c47`，首次升级仍执行旧 PID1、动态链接器、libc、MTD 驱动及内核复位链。上传的新 ROM 不会提前替换已经运行的内核或 PID1。新静态 worker 的 PID1/FD3/独占租约/private tmpfs 准入，也不是可独立从旧 SSH 会话调用的桥接接口。

旧 `flash_firmware()` 先停服务、运行 hook、保存 Storage，再调用 `/tmp/mtd_write -r write`。其保存失败、hook 等待、写后动态依赖及旧重启链的问题，不能由目标镜像中的修复追溯消除。只替换旧 `/tmp/mtd_write`、伪造状态文件、发送旧升级事件或复制新 rc，均不构成已验证的首次迁移方案。

此前一次失联后，仅断电再通电即恢复；历史完整 Flash 读回等于 efd2。它支持镜像已写入且能够冷启动，不能唯一证明失联卡在关机、内核复位、供电、内存还是网络恢复阶段。缺少故障当时的串口和复位原因证据，就继续保留这些区别。

## 当前候选的写前与写后行为

写前需要成功的配置保存、受限 hook、可信静态 helper 暂存、独占操作租约、服务交接及硬件看门狗禁用确认。写入器在私有状态进入 `MAYBE_WRITTEN` 前验证镜像、快照及设备接口，并检查内存锁页。固件设备单次 write 最多 64 KiB；正短写继续，EINTR 重试，零进展和异常长度失败。

`mlockall()` 在本内核可能忽略内部错误。额外的逐范围 `mlock()` 检查只证明相应调用和内存范围的成功，不能代表整个系统永不缺页、所有管理进程可存活或总峰值内存已验收。上传文件、对齐快照、两个进程的映射、锁页、页表、内核缓冲及其它业务都占用内存；镜像加快照的字节数不能当作总 RSS。

worker 不继承 PID1 的特殊 OOM 豁免。它在大快照分配之前通过已检查的 procfs 文件写入并读回自身 `oom_score_adj=-1000`；设置、元数据或读回失败都在擦写前拒绝。proc 的每次 write 都是完整整数，因此正短写直接失败，不续写后缀。该设置排除普通 OOM victim 选择，却可能使 SSH/Web/DNS 等其它进程被选中；分配等待、ENOMEM、内核 panic、已存在的终止状态和显式 SIGKILL 仍不能排除。它不提供整机 OOM 存活或远程管理保证。

候选内核还检查 Winbond 可选 SR3 调整的写使能及写入结果。初始 SR3 读取失败或无需调整时，保留原来的跳过行为；需要调整时先确认 ready，再重新读取 SR3 并重新判断 DRV，使用新值保留其它位，避免覆盖等待期间刚完成的寄存器更新。重新读取失败或已不需调整就跳过，WREN 失败也不发出 SR3 写命令。任何已尝试的 SR3 写命令，包括返回传输错误的命令，都必须经过 ready 检查；无法确认 ready 时，错误沿 scan/probe 返回并阻止 MTD 注册。已经确认 ready 的可选调整失败只警告并跳过，不声称驱动强度设置成功。

该修复保留原来的 DRV 位掩码、目标强度、06h/11h 非易失性写路径和时钟，不切换为 50h 易失性写。依据为 [Winbond W25Q128FV 数据手册](https://www.winbond.com/resource-files/w25q128fv_revhh1_100913_website1.pdf) 的 7.1.12、8.2.5 节；这不是对本机芯片型号的重新确认。现有 ready 轮询有 jiffies 截止，但底层 SPI 锁/队列完成等待不构成端到端启动时限；跳过的路径也不证明所有历史 Flash 状态均已清理。新内核仍不能追溯修补当前 efd2 的首次升级。

MT7621 SPI 控制器的失败路径也必须先释放已持有资源：不可用的输入时钟在注册前拒绝，分配、显式设备树 reset 和注册错误按获取顺序逆序清理。无 reset 属性或关闭 reset-controller 配置的历史兼容行为保留；不改复位寄存器、时钟分频或正常传输顺序。取时钟失败的日志现在打印实际错误码，返回值本身不变。卸载先在时钟仍开启时注销并清理队列，保存时钟指针后再释放时钟，避免访问已释放的 master 私有数据。零长度读取返回确定成功，FIFO 字节在移位前转为 u32，消除未初始化返回和有符号移位未定义行为。这些是软件反例及隔离模型验证，不构成实际 reset、SPI 队列时限或历史失联根因证明。

动态 conf-script 的退出0不能覆盖收集器失败。在当前dnsmasq单线程、没有其它waiter抢收同一child的前提下，候选在fork前持有SIGCHLD阻塞并拒绝自动回收处置，失去子进程身份后不再重查同一个数值并发信号；所有TERM/KILL在唯一回收前完成，之后只以signal-0探测原PGID。只有已回收owned leader、进程组探测明确ESRCH、信号上下文恢复成功且发布前未观察到取消，才接受输出。信号发送报错不能充当清理成功，但独立确认组已消失可以证明无需再终止；残留、EPERM探测、未知或超时都拒绝。PID/PGID复用和仅剩僵尸可能导致保守拒绝，主动setsid/命名空间逃逸的root脚本及不返回的内核调用仍不在保证内。生成快照和普通--test使用同一收集器；新固件不追溯修补efd2首次升级。

若确定未创建任何 writer 子进程，且父进程信号状态可靠，可按写前失败恢复原来运行的服务。只要已经创建过子进程，就不能仅靠缺少状态记录、超时、信号或异常返回推断没有写入。正常 SAFE20 加认证 PREWRITE 才能走另一条恢复路径。

进入可能写入状态后，父进程保留禁止状态，不再执行旧 rootfs 的日志、状态解析或二次复位。worker 完整读回相等后请求一次 raw reboot；该系统调用仍经过内核 reboot notifier、usermode helper、device shutdown、syscore 和 MT7621 machine restart，并非独立硬复位。内核设备 shutdown 可能停止看门狗；超时定时器、SSH 计划任务或普通 reboot 都不能冒充独立回滚。

## 后续现场维护的放行条件

1. 有人能操作网线、电源及经过确认的恢复入口；现场电脑保留候选、当前已知可启动的精确 TRX、对应配置和校验清单。只有公网 SSH/Web 时不安排无人值守首次迁移。
2. 先检查当前 LAN 管理：直连 LAN1/2，记录链路、实际 DHCP 地址/网关，核对设备身份及版本，再检查 Web/SSH。公网超时本身不是重刷依据。不要用 Reset 恢复出厂来代替定位。
3. 在维护前刷新配置与固件备份并验证摘要；配置可能在旧快照后变化。明确分清精确 TRX、原始 firmware 分区和含私密数据的整片文件；普通固件更新不上传整片。
4. 预先核实本机 Bootloader 的入口、地址、板型、16 MiB 布局、禁止自动启动以及写后读回能力。离线识别到 Breed 字符串、官方目录存在 K2P 文件，都不证明本机恢复页可用。缺少任何写前必需能力时停在准备阶段，不开始擦写。
5. 首次迁移优先使用已验证的独立恢复环境，仅更新 firmware，保留 Bootloader、Factory、Config 和 Storage。不借助待覆盖的旧 Linux 首次升级链。必须按实际恢复环境确认操作，不提供未经本机验证的通用按键时长、LED 次数或盲写命令。
6. 写完保持在恢复环境，按精确 TRX 长度读回并比对 SHA256；若核对原始分区，还须分别核对写入范围、擦除对齐和尾部规则，不能把两个不同长度文件直接视为相等。校验不通过或写入进展未知时不启动、不反复断电。
7. 读回通过后再在授权窗口启动。依次验收有线 LAN/SSH/Web、WAN 地址与上级映射、DNS/DHCP、WiFi、硬件 NAT、IPTV、负载及重启。保留串口、boot_id、版本、内存/交换、接口计数和看门狗记录，分别区分冷启动与热复位。

## 回滚顺序

- 公网失联但 LAN 可用：先保留日志和配置，检查 WAN、映射及身份；不要自动再发升级事件。若确需回退，使用已验证的恢复环境。
- 新版可启动但业务不合格：保留故障证据，优先回到与当前配置快照匹配、已知可启动的 efd2 精确 TRX。更早 r14 保留为单独的历史回滚选择，不混用配置快照。
- LAN/SSH 均不可用：确认写入已经结束后，现场进入预先验证的 Bootloader 恢复环境，仅恢复 firmware 并读回，再启动。不要覆盖 Bootloader、Factory 或上传 ALL 文件。
- 已知完整写入但复位卡住：保留串口和最后状态，在确认不再擦写及授权允许后才进行受控断电启动。恢复页、供电或链路也异常时停止软件重刷，转现场电源/串口诊断。
- 配置恢复单独决策：CFG、Storage 目录 tar、Web 所需 TBZ 与原始分区格式不能互换；恢复会覆盖维护后的改动。单槽设备没有自动切换旧固件的能力。

每轮候选的完整提交、来源锁、CI run、固件大小/SHA256、离线证明和具体本机备份路径由该轮交付清单记录。本轮无设备操作；写后热复位、真实内存压力及首次迁移必须保持“未实机验收”。
